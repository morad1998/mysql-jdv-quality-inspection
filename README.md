# MySQL JSON Duality Views Quality Inspection

Oracle ACE bounty project demonstrating how normalized relational
MySQL tables can remain the system of record while JSON Duality
Views provide document-oriented access for applications and AI agents.

## Project status

Day 0 - Environment and prerequisite validation in progress.

## Selected runtime

- MySQL Community Server 9.7.2
- Docker image: mysql:9.7.2
- Host database port: 3307
- Node.js: 24.19.0
- npm: 11.17.0

## Planned application

- Normalized manufacturing quality-inspection schema
- MySQL JSON Duality Views
- Node.js and TypeScript API
- React and TypeScript web application
- Optional guarded AI quality assistant

## Evidence rule

No capability is considered complete until it is demonstrated with
executed commands, actual output, JSON verification, and relational
verification.

## Security

Do not commit .env files, passwords, tokens, private keys, internal
company data, or production connection details.
